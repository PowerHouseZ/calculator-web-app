# Calculator Web App 🧮

## 🚀 Features

- Basic arithmetic operations (add, subtract, multiply, divide)
- Clear and intuitive user interface
- Responsive layout for desktop and mobile
- Real‑time display updates
- Error‑safe input handling

---

## 🛠️ Tech Stack

- **HTML5** – structure and layout  
- **CSS3** – styling and responsive design  
- **JavaScript (ES6)** – calculator logic and DOM interaction

## 📚 How It Works

1. User clicks buttons on the calculator interface  
2. JavaScript captures the input and updates the display  
3. Expressions are evaluated using built‑in JS operations  
4. Results are shown instantly on the screen
